## Repository 1

**Repository Name:**  hydra-floods
**Link:**  https://github.com/Servir-Mekong/hydra-floods

### Purpose
This project uses Sentinel-1 imagery to create high quality maps of surface water for flood application.

### Repository Structure
One file that stood out was the getting-started.md file, which contains examples of what can be done with this project. I also noticed that there were docs like floods.md and corrections.md that only contained a few lines of code. I am not sure that I fully understand why those smaller docs are included individually versus all in one doc.

### Documentation
I found the README for this project very helpful. It contains an introduction, example, how to get in touch, how to contribute, and citations. 

### Activity
It appears to be somewhat maintained. There are many commits from 5-6 years ago, which I assume may be when this project was started. There are a few updates from 1-3 years ago. It does not look like anything has been updated very recently. 

### Key Observation
One thing that this project does well is including examples and explanations of how the project works and can be applied. It also includes clear README, CITATION, CONTRIBUTION and CODE_OF_CONDUCT files that would be very helpful for someone looking to contribute to this project or adapt it for another similar use.

## Repository 2
**Repository Name:**  into-r-spatial-analysis
**Link:**  https://github.com/nickbearman/intro-r-spatial-analysis
### Purpose
This project aims to provide an introduction to spatial analysis in R. It contains files showing how to download and manipulate data using R, as well as how to create final maps for export. 

### Repository Structure
One file that stood out to me is the glossary. It has a list of terms that are used in the course and definitions for each of the terms. I also noticed that there are many script examples and output examples so that you can see what the final maps look like. 

### Documentation
I found the README for this project to be somewhat helpful. It contains the basic information about what the project is and where to find more details. I personally thought it could include a little more information about how you can apply what is learned in the course and what the contribution criteria are.  

### Activity
This repository appears to be updated fairly regularly. There are regular updates over the course of the last year. 

### Key Observation
Something that I think this project does well is including both the scripts and the output from the scripts so that anyone doing the course understands what the information can be used to create. I also think it does a good job of providing regular updates with a clear statement about when to expect updates and when the last update occured.
