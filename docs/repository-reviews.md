## Repository 1

**Repository Name:**  hydra-floods
**Link:**  https://github.com/Servir-Mekong/hydra-floods

### Purpose
This project uses Sentinel-1 imagery to create high quality maps of surface water for flood application.

### Repository Structure
One file that stood out was the getting-started.md file, which contains examples of what can be done with this project. I also noticed that there were docs like floods.md and corrections.md that only contained a few lines of code. I am not sure that I fully understand why those smaller docs are included individually versus all in one doc.

### Documentation
I found the README for this project very helpful. It contains an introduction, example, how to get in touch, how to contribute, and citations. 

### Activity
It appears to be somewhat maintained. There are many commits from 5-6 years ago, which I assume may be when this project was started. There are a few updates from 1-3 years ago. It does not look like anything has been updated very recently. 

### Key Observation
One thing that this project does well is including examples and explanations of how the project works and can be applied. It also includes clear README, CITATION, CONTRIBUTION and CODE_OF_CONDUCT files that would be very helpful for someone looking to contribute to this project or adapt it for another similar use.
